# FSFD-DVI Reproducibility Package

This repository contains the numerical code for the manuscript

> Fuzzy stochastic fractional-order delay differential variational inequalities: well-posedness and a convergent numerical scheme

The code generates the figures used in the numerical experiments section and records the 200-path convergence study used in the RMSE table.

## Requirements

- Python 3.10 or newer (tested with Python 3.13)
- `numpy`
- `scipy`
- `matplotlib`
- `numba`

Install the dependencies with:

```bash
pip install -r requirements.txt
```

## Repository layout

```text
.
├── README.md
├── requirements.txt
├── code_supplement/
│   ├── revised_paper_figures.py      # Fig1-Fig5 and Fig7-Fig9
│   ├── convergence_reproduction.py   # Fig6 (authoritative, 200 paths)
│   ├── generate_fuzzy_fig.py         # Fig10
│   ├── convergence_slope.txt
│   └── convergence_results.json
└── fig/                              # Final paper figures
```

## Reproducing the figures

Run all commands from the repository root.

### Fig1-Fig5 and Fig7-Fig9 (sensitivity, stability, long time, ablation, comparison)

```bash
python code_supplement/revised_paper_figures.py
```

Output files are written to `figures_revised/`:

- `Fig1_p_Sensitivity.png`
- `Fig2_gamma_Sensitivity.png`
- `Fig3_tau_Sensitivity.png`
- `Fig4_Stochastic_Stability.png`
- `Fig5_Control_Variable.png`
- `Fig6_Convergence_Rate.png` (legacy 15-path output, not used in the paper)
- `Fig7_Global_Stability.png`
- `Fig8_Ablation_Study.png`
- `Fig9_Advanced_Comparison.png`

**Important:** the paper uses the 200-path version of Fig6 generated by `convergence_reproduction.py`; do not use the `Fig6` produced by `revised_paper_figures.py`.

### Fig6 (authoritative 200-path convergence study)

```bash
python code_supplement/convergence_reproduction.py --runs 200
```

This writes:

- `fig/Fig6_Convergence_Rate.png`
- `code_supplement/convergence_results.json`
- `code_supplement/convergence_slope.txt`

### Fig10 (genuine fuzzy example)

```bash
python code_supplement/generate_fuzzy_fig.py
```

This writes `fig/Fig10_Fuzzy_Level.png`.

## Recorded 200-path convergence result

The committed result files were generated with:

```bash
python code_supplement/convergence_reproduction.py --runs 200
```

Current values:

- slope = 0.3463
- standard error = 0.0052
- 95% confidence interval = [0.3361, 0.3566]
- `N_ref = 8000`

All per-grid RMSE values are stored in `code_supplement/convergence_results.json`.
